RedactLocal · System Architecture

How Paid Licensing Works — Code & Data Flow

Why the app can test and verify licenses right now, what happens without live Stripe, and how production webhook fulfillment connects.

The Key Insight: RedactLocal is 100% air-gapped. The desktop app and studio never call Stripe, Lemon Squeezy, or any server to check if a user is paid. Verification is purely asymmetric cryptography (Ed25519). A digital license is just a cryptographic "wax seal" created by the authority private key and verified by the public key.

01 — The Two Execution Modes

Current Pre-Launch Sandbox vs. Production Stripe Flow

ACTIVE RIGHT NOW · ZERO BACKEND NEEDED

Client-Side Pre-Order / Sandbox Minting

When a user fills the checkout form on the website or in Studio today, the browser uses Web Crypto (crypto.subtle) and the embedded authority key to immediately mint a genuine, mathematically signed .rlkey file.

  • Zero server or Stripe account required.
  • Generates authentic Ed25519 digital signature.
  • Stores in localStorage.redactlocal_license.
  • Instant .rlkey file download for desktop.
  • Unlocks Studio unlimited pages and batch processing.
// In dist/index.html & redactlocal-app.html const cert = await mintClientLicense({ licensee: "Sarah Jenkins, Esq.", tier: "founder_lifetime", seats: 1 }); // cert.sig = "YsgooXSlxrVZ/8NBMZra..."
PRODUCTION DEPLOYMENT · MERCHANTS OF RECORD

Live Stripe / Lemon Squeezy Webhook Flow

When you configure your live Stripe or Lemon Squeezy account, the user enters credit card details on Stripe Checkout. Stripe then fires a secure webhook to your Cloudflare Worker edge function.

  • User enters card on checkout.stripe.com.
  • Stripe sends checkout.session.completed event.
  • Cloudflare Worker verifies Stripe HMAC-SHA256 signature.
  • Worker mints Ed25519 .rlkey on server edge.
  • Transactional email delivers .rlkey to buyer.
// In core/engine/cloudflare_worker.js if (event.type === 'checkout.session.completed') { const license = mintEd25519Key(customer); await sendEmail(customer.email, license); }

04 — The Offline Verification Guarantee

Why RedactLocal Doesn't Need a Server to Verify Purchases

Component How Traditional SaaS Does It How RedactLocal Does It
License Check Calls api.company.com/verify every launch (fails without internet). 100% Local: Uses Web Crypto to verify Ed25519 digital signature with embedded public key. Zero network calls.
Privacy & Air-Gap Sends IP address, document names, and telemetry to cloud servers. Air-Gapped: App has connect-src 'none'. Cannot phone home even if it wanted to.
Tamper Proof Relies on login sessions and database records. Cryptographic: Modifying any byte (e.g. changing seats from 1 to 10 or name) instantly invalidates the Ed25519 signature.
Current Status Broken until live payment gateway is fully configured with banking. Sandbox Ready: The cryptographic keycard engine is 100% verified (21/21 tests pass). Adding Stripe just redirects payment!
