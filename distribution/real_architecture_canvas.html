Web Leak Checker PWA REAL

dist/index.html (deployed to GitHub Pages): Client-side audit scanner. Decompresses /FlateDecode streams, reads /Info author metadata, scans AcroForm /V dictionaries.

LAYER 2 · REDACTION ENGINE & FORENSICS

How Documents Are Actually Processed Today

In-Browser Custom Redaction REAL (RASTER FLATTEN)

generateCleanRedactedPdf(): When a user drops a custom PDF and downloads: Draws black boxes on HTML5 <canvas> → converts to image/jpeg (0.95 quality) → writes new clean PDF-1.4 file. Security: 100% leak-proof (text bytes are eradicated), but output is flattened image PDF.

Sample Presets (W9, JMI, Subpoena) REAL (OFFLINE FITZ)

For the 5 built-in demo cases, the UI loads authentic pre-redacted PDF binaries generated by PyMuPDF (fitz) in redaction-test-lab/ with actual vector font stripping.

redaction-test-lab/hardened_verifier.py & run_corpus_tests.py: 30-document multi-jurisdiction test corpus audited across 7 forensic oracles. 30/30 tests pass locally via Python/PyMuPDF.

03 — End-to-End Runtime Trace

What Actually Happens When You Drop a PDF Today

1. Drop PDF handleFile() reads raw bytes via FileReader.
→
2. PDF.js Parse pdfjs.getDocument() decompresses streams in browser memory.
→
3. Regex PII Match statutory_patterns.js scans strings for SSN, PAN, Aadhaar.
→
4. User Review Redaction queue rendered on screen. User toggles checkboxes.
→
5. Export PDF Canvas rasterizes with blackouts → clean PDF downloaded.
